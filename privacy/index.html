Privacy Policy

Last updated: May 2, 2026

Overview

This Privacy Policy explains how Goose collects, uses, stores, and shares data when the bot is used in Discord servers or direct messages. Goose collects only the data needed to provide bot features, moderation tools, AI replies, debugging, and script hosting.

Data Collected

Depending on enabled features and user actions, Goose may process or store:

  • Discord user IDs, usernames, display names, server IDs, channel IDs, message IDs, role IDs, and permission information.
  • Messages, prompts, replies, command inputs, message links, and limited recent or replied-message context used for AI responses.
  • Attachments submitted for AI or loadstring features, including supported text files, scripts, still images, sticker metadata, and image OCR or captions.
  • Server configuration such as prefixes, log channels, ban channels, tempban entries, command settings, autoresponse triggers, ignored user or role IDs, knowledge lines, blacklists, and whitelists.
  • Hosted loadstring data such as Discord user ID, username slug, script name, script content, public path, timestamps, size, and version history.
  • AI debug logs when debug mode is enabled for a server, including generated AI input payloads, message metadata, provider errors, and response previews.
  • Operational logs needed to diagnose errors, provider rate limits, script-hosting failures, and bot availability issues.

How Data Is Used

Goose uses collected data to:

  • Respond to commands, mentions, replies, direct messages, and configured autoresponse triggers.
  • Run moderation actions and post moderation logs to configured channels.
  • Generate AI replies using relevant message context, attachment context, server metadata, and runtime settings.
  • Host, list, update, remove, and serve user-submitted loadstring scripts.
  • Apply rate limits, blacklists, whitelists, command restrictions, and safety checks.
  • Debug failures, prevent abuse, maintain service reliability, and improve bot behavior.

Goose does not sell personal data.

Third Parties

Goose runs on Discord and uses Discord APIs to receive events and perform bot actions. For AI features, relevant prompts, message context, attachment-derived text, image descriptions, and metadata may be sent to configured AI providers such as Groq, Cerebras, or Hugging Face.

When users ask for live executor status or web information, Goose may request data from public web pages, WEAO, or URLs included in the user's message. Those third-party services process data under their own policies and operational practices.

Public Content

Loadstring hosting creates public raw script URLs, commonly under https://sc.afkar.lol/. Do not submit secrets, tokens, private keys, credentials, private code, or personal data as script content.

Script links and old-version links can be accessed by anyone who has the URL. Server moderation logs are visible to people who can view the configured log channel.

Retention

Server configuration is kept until it is changed, removed, or no longer needed. Tempban records are kept until the tempban expires or is cleared. Hosted scripts and their version history are kept until removed by the user, removed by the bot operator, or deleted as part of maintenance or abuse response.

AI debug logs and operational logs may be kept while needed for troubleshooting, abuse prevention, and reliability. Data sent to Discord or third-party providers may be retained according to those services' policies.

Choices

Server administrators can remove Goose from a server, disable commands, adjust server configuration, and choose whether to use features such as AI debug logging, autoresponses, log channels, ban channels, and loadstring hosting. Users can avoid submitting private content to the bot and can remove their hosted loadstrings using the bot's removal command where available.

Security

Goose uses access controls, Discord permissions, authenticated internal script-hosting APIs, and operational safeguards to limit unauthorized access. No system can be guaranteed completely secure, so users should not send secrets or highly sensitive information to the bot.

Contact

For privacy questions, data access, correction, deletion, abuse reports, or safety requests, contact the Goose bot owner, afkar, through Discord.
