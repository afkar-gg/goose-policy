Service Description

Goose is a public Discord AI chatbot and community management application that provides:

  • AI Chatbot & Conversational Inference: Multi-provider conversational responses (Groq, Cerebras, Hugging Face) with automated fallback, reply-chain context tracking, and attachment text/image inspection.
  • Moderation Tools & Utilities: Comprehensive moderation commands (ban, kick, timeout, blacklist, tempban enforcement) and configurable mod logging.
  • Member Facts Lookup: On-demand querying of guild member roles, permission levels, display names, and nicknames without off-platform storage.
  • Presence & Online Member Dashboard: Real-time visualization of server member availability (online, idle, dnd, offline) and active games/applications for community event scheduling and engagement.
  • Server Utilities: Customizable command prefixes (default: s.), autoresponse triggers, server knowledge bases, and loadstring hosting utilities.

Certain administrative and moderation features are restricted to server administrators, moderators, bot operators, or creator-whitelisted users.

Privileged Intents Commitments

In alignment with Discord's Privileged Gateway Intent requirements, Goose operates under the following explicit operational commitments:

  • In-Memory Message Processing: Message content accessed via Message Content Intent is processed strictly in-memory during active command parsing or AI chat inference, and is never stored off-platform (outside of Discord).
  • Zero AI Model Training: Goose does not use user messages, prompts, or attachments to train machine learning or AI models. Prompts are used exclusively for real-time inference generation.
  • On-Demand Member Facts: Guild member data accessed via Server Members Intent is fetched on-demand, cached ephemerally in volatile memory for at most 120 seconds, and never persisted off-platform.
  • Presence Tracking & Opt-Out: Presence data accessed via Presence Intent is evaluated in real-time solely for the online member status dashboard and is never persisted off-platform. Users can opt out of presence tracking at any time using s.presence optout or /presence optout.

Moderation

Server administrators and moderators are responsible for configuring and executing moderation features within their servers. Goose provides utilities such as timeouts, kicks, bans, tempbans, blacklist management, command restrictions, and moderation logging when authorized by server permissions.

Moderation actions may be logged directly to the server's configured moderation log channel, including Discord user IDs, usernames, moderator IDs, timestamps, and provided reasons.
